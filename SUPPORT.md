# Support

Start with the [README](README.md), [Docker operations](docs/docker.md), [provider configuration](docs/providers.md) and [known limits](docs/limits.md).

Use [GitHub Issues](https://github.com/lucas-lepajollec/sillage/issues) for reproducible bugs and focused feature requests. Include the image tag/digest, architecture, sanitized error and a minimal original or shareable subtitle fixture. Do not upload copyrighted episodes, API keys, private logs or config databases.

Security reports belong in the private route described in [SECURITY.md](SECURITY.md). Sillage is maintained as a personal project; response times are not guaranteed.
